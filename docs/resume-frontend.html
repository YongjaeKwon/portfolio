소개

입력, 진행, 오류 상태가 한눈에 보이는 업무 화면을 만듭니다. 필요한 API와 데이터 처리도 직접 연결합니다. 실무에서는 Vue 화면부터 Spring API, SQL, 배포까지 맡고 있고, React와 TypeScript 프로젝트에서는 동적 입력 폼과 운영 화면, 사용자 흐름 테스트를 만들었습니다. 운영 담당자와 함께 업무 순서와 예외를 정리하고, 배포 뒤 드러난 문제도 고쳐 왔습니다.

핵심 성과

  • Vue 공통 상태 누수로 생긴 첨부파일 오연결 원인 제거 — 화면마다 새 상태를 만들도록 바꾸고, 서버 저장 단계에서도 다른 CE의 첨부파일 그룹이면 거부하게 해 이중으로 막았습니다.
  • 300~400건 대량 다운로드를 진행 상태가 보이는 흐름으로 — 작업 ID를 먼저 받고 대기 · 진행 · 완료 · 실패를 보여 주며, 새로고침 후에도 같은 작업을 이어서 확인합니다.
  • 종이 점검을 화면으로 옮긴 학교 방문 점검 — 일정 승인부터 확인서까지 한 흐름으로 만들고, 2026.09 기준 71개교에서 점검표 14,882건이 이 화면으로 저장됐습니다.
  • 4개 교육청 학부모 공개 접수 화면 — 로그인 없이 모바일에서 동의 · 배송 예약 · QR 배부 확인을 마치게 하고, 마감 잠금과 오류 화면까지 실사용 환경을 처리했습니다.
