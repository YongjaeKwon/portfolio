# 서비스·자재 관리 시스템(SR30)

서비스 접수·처리와 자재 재고, 실적을 관리하는 SR30에서 화면·Java 서비스·MyBatis SQL을 추가·수정했습니다. 우정사업 업무 화면 개발에도 참여했습니다.

- 백엔드·DB: Java 8 · Spring MVC(eGovFrame 3.9) · MyBatis · Oracle
- 프론트엔드: JavaScript · Nexacro 17

## 기간별 서비스 실적을 비교하는 조회 화면

EPSON 서비스 건수를 조회 기간과 제품군에 따라 확인하는 기능을 개발했습니다. Java 서비스에서 조회할 월 목록을 만들고 MyBatis SQL에서 월별 건수를 집계했습니다. Nexacro 화면도 같은 기간에 맞춰 열을 구성해 인도·반송·취소 건수와 소계를 표시합니다.

## 전화번호로 서비스 내역이 검색되지 않는 오류 수정

서비스 내역 화면에서 전화번호로 검색되지 않는 오류를 수정했습니다. 입력 컴포넌트와 데이터셋의 연결을 정리하고 Java 서비스의 전달 파라미터를 추가했습니다. SQL은 입력한 번호를 기존 암호화 방식으로 변환해 일반전화·휴대전화 및 보조 연락처와 비교하도록 작성했습니다.

## 재고 검증 SQL의 날짜 조건과 화면 검색 분기 정리

기준일 재고와 자재 입출고 내역을 비교하는 기능에서 현재 재고 선택 여부에 따라 집계 날짜 범위를 나눴습니다. 날짜 컬럼의 TO_DATE를 제거해 저장값과 검색값을 직접 비교하고 화면 체크박스 값에 맞게 MyBatis 조건 분기를 수정했습니다. 조회 화면의 날짜 범위 검사와 표시 방식도 보완했습니다.

## 접속·개인정보 다운로드 이력 조회

로그인·화면 접속·개인정보 다운로드 기록을 조회하는 화면과 SQL을 개발했습니다. 기존 로그를 부서·사용자·기간별로 집계하고 메뉴 이름을 연결해 어떤 화면에서 사용한 내역인지 확인하도록 했습니다.

## 우정사업 장비 설치·철거 등록

장비 관리번호로 대상 정보를 조회하고 설치·철거 내역을 입력하는 Nexacro 화면과 MyBatis SQL을 추가했습니다. 작업 구분에 따라 입력 화면을 바꾸고 대상 장비 조회와 등록 요청을 연결했습니다.

사내 소스와 실제 업무 화면·데이터는 공개하지 않습니다.
