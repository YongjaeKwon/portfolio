# 교육용 단말 운영 시스템(TSMS)

> 공개용 설명입니다. 실제 사내 코드, 운영 URL, 계정·고객사 정보와 저장 데이터는 제외했습니다.

서울시교육청 디벗 사업에서 교육용 단말 11만여 대의 등록, 보급, 설치, A/S와 점검 업무를 관리하는 시스템입니다. WebSquare·JSP 화면과 Spring MVC 서버, MyBatis 쿼리를 함께 개발하고 운영 담당자와 요구사항 협의·검수·배포를 진행하고 있습니다.

## 상세 사례

### 1. 외부 API 키 노출 제거와 호출 경로 공통화

주소 검색과 교육행정정보 연동 키가 브라우저 코드에 포함돼 있었고, 연결 정보가 바뀔 때마다 관련 화면을 각각 수정해야 했습니다. 키만 교체하면 같은 문제가 반복된다고 판단해 외부 호출 책임을 화면에서 서버로 옮겼습니다.

외부 API 요청을 대신 처리하는 공통 Controller와 Service를 만들고 키와 외부 URL은 서버 설정으로 분리했습니다. 기존 25개 WebSquare 화면은 같은 서버 경로와 공통 응답 형식을 사용하도록 전환했습니다.

브라우저에서 확인할 수 있던 API 키를 서버로 회수하고, 연동 정보의 변경 지점을 화면별 코드가 아닌 공통 서버 경로로 모았습니다.

### 2. 중고거래 게시글 모니터링 업무 전산화

운영팀은 여러 중고거래 플랫폼을 키워드와 지역별로 반복 검색한 뒤 의심 게시글, 캡처와 조치 내용을 따로 관리하고 있었습니다. 내부 보안과 외부 사이트 정책 때문에 서버 요청이나 iframe으로 게시글을 가져올 수 없다는 제약도 있었습니다.

검색과 게시글 확인은 사용자가 새 탭에서 수행하고, 시스템은 검수자가 붙여넣은 URL 문자열만 분석하는 방식으로 범위를 정했습니다. 프래그먼트와 추적 파라미터를 제거한 뒤 사이트별 규칙으로 플랫폼과 게시글 ID를 찾고, ID가 없으면 정규화한 전체 URL을 기준으로 중복을 확인합니다. 사이트 판별식은 기준정보 화면에서 관리해 URL 형식 변경에 대응하도록 했습니다.

검색 링크 생성, 게시글 링크와 캡처본, 판매 정보와 처리 이력을 한 흐름으로 연결했습니다. 서버는 외부 게시글에 직접 접속하지 않습니다.

```java
String normalized = normalizeUrl(inputUrl);
SiteRule site = findMatchingRule(normalized);
String postId = extractPostId(site.getPostIdPattern(), normalized);

return postId != null
    ? existsBySiteAndPostId(site.getSiteCode(), postId)
    : existsByNormalizedUrl(normalized);
```

### 3. 대량 단말 등록 검증과 QR 발급

엑셀로 단말을 등록할 때 생산입고 내역에 없거나 다른 학교·사용자에게 이미 등록된 일련번호가 섞일 수 있었습니다. 저장 전에 생산입고 마스터와 기등록 상태를 확인하고, 오류 단말은 원인과 기존 소유 정보를 함께 반환하도록 검증 순서를 앞당겼습니다.

정상 데이터만 일괄 등록과 QR 발급 흐름으로 연결했으며, QR에는 DB 식별자를 직접 넣지 않고 외부 노출용 토큰을 사용했습니다. 이 기능은 운영팀의 등록 업무와 공장 전용 프린터 출력에 사용되고 있습니다.

### 4. 현장 점검과 재점검 이력 관리

종이 점검표로는 학교별 진행 상황을 한눈에 확인하기 어려웠고, 분실·미지참 단말의 2차·3차 재방문 결과도 이어서 관리하기 어려웠습니다.

학교 완료 여부만 저장하지 않고 단말별 점검 회차와 결과가 다음 방문으로 이어지는 구조로 정리했습니다. 역할과 진행 상태에 따라 입력·조회 모드를 나누고, 필수값 누락 시 첫 오류 항목으로 이동하도록 했습니다. 미완료 단말은 이전 사유와 함께 다음 점검 차수로 넘기고 터치 서명, 미저장 이동 경고, 확인서와 결과 파일 발급을 같은 흐름에 포함했습니다.

학교·단말별 점검과 재점검 이력을 시스템에서 관리하고 있습니다. 2026년 7월 기준 119개 대상 학교에서 약 3,800건의 점검 데이터가 기록됐습니다. 이 수치는 개발 성능이 아니라 실제 운영 범위를 보여주는 기준입니다.

## 사용 기술

Java, JavaScript, WebSquare5, JSP, Spring MVC, MyBatis, MariaDB, Maven, Tomcat, Linux

## 공개 범위

사이트에는 업무 맥락과 설계 판단을 설명하기 위한 축약 코드만 표시합니다. 실제 정규식, 테이블명, API 주소, 인증 정보, 학교·학생·단말 데이터는 공개하지 않습니다.
